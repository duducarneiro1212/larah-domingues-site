# Larah Domingues

Feed de fotos e videos (sem pagamento e sem login).

## Como abrir
1. Abra a pasta no VS Code (Arquivo > Abrir Pasta).
2. Instale a extensao Live Server (opcional).
3. Clique com o botao direito em index.html > Open with Live Server.
   Ou de dois cliques em index.html para abrir no navegador.

## Adicionar fotos
Coloque o arquivo na pasta img/ e adicione uma linha na lista POSTS do script.js (exemplos no topo do arquivo).

## Arquivos
- index.html: estrutura
- style.css: visual (cores em :root)
- script.js: galeria e foto ampliada
